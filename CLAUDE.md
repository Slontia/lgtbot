# Commit Message Rules

If a commit modifies a specific game, the title must start with `<游戏名>: ` (e.g., `opencomb: fix bug`). The game name should begin with a lowercase letter, as in the example.

For all other commits (bot_core, CI, game_framework, game_util, etc.), do **not** use a `<prefix>: ` format in the title.

The commit message **title** must begin with a **lowercase ASCII letter** (`a`–`z`). Examples: `add grpc server`, `opencomb: fix bug` (`o` is lowercase). Avoid `Add grpc server` or `Fix login`.
